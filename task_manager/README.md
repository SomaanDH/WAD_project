## Setup Instructions
1. Install and start XAMPP.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Copy the whole `task_manager` folder into `C:\xampp\htdocs\`
   (so the path is `C:\xampp\htdocs\task_manager\`).
4. Open phpMyAdmin at http://localhost/phpmyadmin
5. Click the **Import** tab, choose `database.sql`, click **Go**.
6. Open `db.php` and check the credentials (host localhost, user root, empty password).
7. Open the app at http://localhost/task_manager/

## Feature List
- Create tasks (title, description, category, priority, due date)
- Read/list all tasks in a table
- Edit tasks, including a "completed" checkbox
- Delete tasks (POST form only, not a GET link)
- Server-side validation on all fields
- Flash success/error messages using sessions
- Challenge: overdue tasks are highlighted in red
